Incremental tokenization

Worker threads
Lazy loading
Virtual scrolling
Why Incremental Parsing Matters

Without incremental parsing:

Every key press
→ Parse whole file

Very slow.

With incremental parsing:

Only changed subtree updates

Huge performance gain.

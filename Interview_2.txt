Interview Questions — Incremental Rendering
Q1. Why not render all lines?
Answer

Large DOM trees:

Increase memory usage
Slow layout calculations
Cause FPS drops

Virtualization reduces DOM nodes drastically.

Q2. Complexity Improvement?

Without virtualization:

O(n)

With viewport rendering:

O(v)

Interview Questions — IndexedDB
Q1. Why use IndexedDB instead of LocalStorage?
Answer

IndexedDB supports:

Async operations
Large storage
Transactions
Structured objects

LocalStorage is synchronous and blocks UI.

Q2. Why separate persistence service from DB service?
Answer

DB service handles low-level storage.

Persistence service handles:

Business rules
Syncing
Autosave orchestration
Conflict handling

1. Why multiple testing layers?
Answer

Different bugs occur at different layers.

Example:

Unit → logic bugs
Integration → communication bugs
E2E → workflow bugs
2. Why performance testing matters in editors?
Answer

Editors handle:

Huge files
Rapid typing
Complex rendering

Poor performance directly impacts usability.

3. Why E2E tests are expensive?
Answer

They:

Launch browsers
Simulate real users
Are slower
More brittle

But they validate real workflows.

4. Why mock external dependencies?
Answer

Mocks isolate logic and improve:

Speed
Reliability
Determinism
5. Why soak testing matters?
Answer

Some issues only appear over time:

Memory leaks
Event listener buildup
Heap fragmentation
FAANG-Level Learning Outcomes

This testing architecture teaches:

Test pyramids
Browser automation
Performance engineering
CI/CD pipelines

Reliability engineering
